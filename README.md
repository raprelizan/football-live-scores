# ⚽ كورة لايف - Football Live Scores

تطبيق ويب مجاني وحديث لمتابعة نتائج مباريات كرة القدم بشكل مباشر من أشهر البطولات العالمية.

![Node](https://img.shields.io/badge/node-%3E%3D18-brightgreen.svg)
![React](https://img.shields.io/badge/react-19-blue.svg)

## ✨ المميزات

### 🎯 الميزات الأساسية
- ⚡ **بث مباشر للمباريات** - شاهد المباريات الحية مع تحديث تلقائي كل 30 ثانية
- 🏆 **دعم البطولات الكبرى** - دوري أبطال أوروبا، الدوري الإنجليزي، الإسباني، الإيطالي، الألماني، الفرنسي
- 📊 **إحصائيات شاملة** - النتائج، الترتيبات، الهدافين، أحداث المباريات
- 🔍 **محرك بحث متقدم** - ابحث عن المباريات والفرق بسهولة
- 🎨 **تصميم حديث وجميل** - واجهة عربية بالكامل مع دعم RTL
- 🌙 **وضع ليلي/نهاري** - اختر الوضع المناسب لك

### 🌍 اللغة والتصميم
- 🇸🇦 **واجهة عربية كاملة** - جميع النصوص والعناصر بالعربية
- ↔️ **دعم RTL** - اتجاه النص من اليمين إلى اليسار
- 📱 **تصميم متجاوب** - يعمل بشكل مثالي على الهواتف والأجهزة اللوحية وأجهزة الكمبيوتر
- 🎨 **ألوان احترافية** - تصميم داكن مع لمسات خضراء وذهبية

### 🔔 الإشعارات والتحديثات
- 🎯 **إشعارات الأهداف** - احصل على تنبيهات فورية عند تسجيل هدف
- 📢 **تغييرات الحالة** - تنبيهات عند بدء المباراة أو انتهاؤها
- ⏰ **تحديثات تلقائية** - بيانات محدثة كل 30 ثانية

## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- pnpm

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/yourusername/football-live-scores.git
cd football-live-scores

# تثبيت المكتبات
pnpm install

# تعيين متغيرات البيئة
cp .env.example .env.local
# عدّل .env.local وأضف مفتاح Football-Data.org API
```

### التشغيل المحلي

```bash
# تشغيل خادم التطوير
pnpm dev

# سيكون الموقع متاحاً على http://localhost:3000
```

### البناء للإنتاج

```bash
# بناء المشروع
pnpm build

# تشغيل النسخة الإنتاجية
pnpm start
```

## 🔌 التكامل مع APIs

### Football-Data.org API
- **الحد الأقصى**: 100 طلب يومياً
- **المميزات**: البطولات، المباريات، الفرق، الترتيبات
- **التوثيق**: https://www.football-data.org/documentation/api

### البيانات التجريبية
عند تجاوز الحد الأقصى أو انقطاع الاتصال، يستخدم التطبيق بيانات تجريبية محفوظة محلياً.

## 🛠️ التطوير

### الأوامر المتاحة

```bash
# التحقق من أخطاء TypeScript
pnpm check
```

### المكتبات الرئيسية

- **React 19** - مكتبة UI
- **Tailwind CSS 4** - تصميم
- **tRPC** - اتصال Client-Server
- **Drizzle ORM** - قاعدة البيانات
- **Shadcn/ui** - مكونات UI جاهزة

## 📱 الصفحات المتاحة

| الصفحة | الوصف | الرابط |
|--------|--------|--------|
| الرئيسية | المباريات الحية والقادمة والمنتهية | `/` |
| تفاصيل المباراة | النتيجة والتشكيلة والأحداث | `/match/:id` |
| البطولات | جميع البطولات المدعومة | `/competitions` |
| الترتيبات | ترتيب الفرق في البطولات | `/standings` |
| الهدافين | أفضل هدافي البطولات | `/scorers` |
| البحث | البحث عن المباريات والفرق | `/search` |
| من نحن | معلومات عن التطبيق | `/about` |
| اتصل بنا | نموذج التواصل | `/contact` |
| سياسة الخصوصية | سياسة الخصوصية | `/privacy` |
